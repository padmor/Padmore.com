# Personal Developer Portfolio — Padmore Yeb

This repository contains the source code for Padmore Yeb's personal developer portfolio.

The application is organized as a modular Next.js App Router project using React, TypeScript, semantic HTML and a custom light-mode CSS design system.

## Quick start

1. Extract `padmore-personal-portfolio-source.tar.gz` if you downloaded the packaged source archive, or clone this repository after the source files are committed.
2. Install Node.js 22 LTS (Node.js 20.9 or newer is required by the selected Next.js version).
3. Run `npm install`.
4. Run `npm run dev` and open http://localhost:3000.

## Important status

This is an initial frontend implementation. Authentication, database persistence, private form submissions, email delivery, production admin authorization and real payment verification still require backend configuration and implementation. Demo forms and cart state must not be treated as production services.

Sample project, member, product, price and analytics content is illustrative. Replace it with verified personal information before public launch. The profile portrait is a temporary placeholder and must be replaced with Padmore's approved photo.

See the application README and `docs/` for architecture, design tokens, module boundaries, QA and performance guidance.
